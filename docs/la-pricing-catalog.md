# Los Angeles pricing catalog — phase B

The checked-in source is [the phase A research JSON](../shared/research/la-pricing-phase-a.json), transcribed from [issue #2's research comment](https://github.com/builder-one-stop/kevin-estimator/issues/2#issuecomment-6241898228). It records 6 suppliers, 25 observations, 20 public prices, 5 missing prices, and **zero prices verified for an exact product, branch, and Los Angeles ZIP**. Product URLs, observed dates, package conversions, verification method, and limitations remain in the JSON. The catalog adapter assigns stable IDs and preserves the research version. It does not fetch current supplier prices.

The built-in references are read-only for operators. An admin can import them into the existing owner-scoped settings catalog for review and later updates. Each managed change increments the record's price version and retains the prior price, date, status, and evidence. The settings row also has optimistic versioning. New estimates copy the selected price and its evidence into each saved line; a later catalog update cannot change that saved snapshot. A locally verified record requires a non-null price, exact ZIP, product URL, and separate local price evidence. A public price does not become local merely because its supplier has a Los Angeles store.

To try the isolated local app, run `node scripts/ai-local-harness.mjs`, open `http://127.0.0.1:5180/__fixture/session`, and choose **Enter test workspace**. This uses ephemeral PGlite and a controlled AI fixture; it does not test real AI or supplier access. In a chat, generate an estimate, choose **Edit document**, expand an item's details, and select a public catalog reference. The displayed source and date are saved with that line. Changing the unit cost or description marks the line manual. For paint, enter area, coats, coverage, and waste, then calculate whole purchasable packages. The coverage and waste values are editable assumptions, not supplier-verified yields. Export the proposal PDF after the estimate finishes saving.

Run `VITE_SUPABASE_URL=http://127.0.0.1:8790/test-supabase VITE_SUPABASE_ANON_KEY=fixture-public-key npm test`, `npm run lint`, `npm run build`, and `node scripts/catalog-phase-b-browser.mjs` for the local acceptance checks. The browser script writes screenshots, saved estimate JSON, and English and Spanish PDF downloads under `evidence/catalog-phase-b/`.

Still pending: branch/ZIP prices, inventory, tax, delivery, private rates, labor productivity, and verified paint yield. Do not use the public observations as confirmed local quotes. No production migration is needed because the existing settings and estimate document JSON fields persist the managed catalog and line snapshots.
